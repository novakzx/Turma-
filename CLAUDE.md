# Turma+

Ver [README.md](README.md) pra stack, setup, variáveis de ambiente, estrutura de pastas e roadmap por fase. Regras que valem pra qualquer trabalho neste repo:

- Nenhuma chave secreta (Anthropic, service role do Supabase) entra no código do app — só em Edge Functions. Variável visível no cliente sempre começa com `EXPO_PUBLIC_`.
- Toda tabela nova em `supabase/migrations/` precisa de RLS habilitada e policy por papel (`aluno`/`professor`/`coordenacao`) — ver o schema inicial pra o padrão já usado (funções `private.current_papel()`, `private.current_escola_id()`, `private.current_turma_id()`, `private.is_staff()`).
- Essas funções ficam no schema `private` (fora do que o PostgREST expõe como API). Se mover mais alguma função de schema, lembre que `ALTER FUNCTION ... SET SCHEMA` atualiza quem a referencia via _policy_ (RLS guarda por OID), mas **não** atualiza chamadas feitas de dentro do _corpo_ de outra função com o schema antigo escrito por extenso (ex.: `public.is_staff()` dentro de outra função) — isso já quebrou aviso em produção uma vez (ver migration `fix_private_schema_internal_refs`). Sempre teste a operação de verdade (não só confie na migration ter rodado sem erro) depois de mexer em RLS.
- Regra de negócio de verdade (cálculo de nota, escopo de aviso, moderação) ganha teste antes de ser considerada pronta.
- Edge Function chamada direto do app (`supabase.functions.invoke`, não trigger/cron) precisa responder o preflight `OPTIONS` com headers de CORS — sem isso o request nem sai do navegador ("Failed to send a request to the Edge Function", sem pista nenhuma até abrir o console). Ver `supabase/functions/chat-estudo/index.ts` pro padrão. Trigger/cron (notificar-aviso, aviso-clima) não precisam disso — são chamada servidor-a-servidor.
- Nunca derive a extensão de um arquivo cortando a URI local por `.` (`uri.split('.').pop()`). No nativo `uri` é `file://...jpg` e isso funciona, mas no **web** o `expo-image-picker` devolve um `blob:http://localhost:8081/<uuid>` sem ponto nenhum — `split('.').pop()` volta a URL inteira (com `:` e `/`) como "extensão" e quebra o nome do objeto no Storage (cria pastas aninhadas indesejadas a partir dos `/` do blob URL). Pegue a extensão do `content-type` da resposta do `fetch(uri)` — funciona igual nos dois targets (ver `fazerUploadImagemPost` em `src/features/feed/api.ts`).
- TypeScript estrito, sem `any` solto. Rode `npm run lint`, `npm run typecheck` e `npm test` antes de considerar uma mudança terminada.
- Nunca calcule um prazo/expiração de segurança (silenciar usuário, token, o que for) com `Date.now()`/`new Date()` do **cliente**. Testando o "silenciar 1 hora" da moderação de chat, o relógio do próprio ambiente de teste estava 4 dias atrasado em relação ao servidor — o prazo gravado já nascia expirado, sem erro nenhum, e a mutação parecia ter funcionado (UI mostrava "Usuário silenciado" normalmente). Corrigido movendo o cálculo pro banco: uma função `security invoker` (`silenciar_usuario`, ver migration `silenciar_usuario_rpc`) que usa `now() + interval` do Postgres — continua sujeita à mesma RLS/trigger de sempre, só tira o "agora" das mãos do cliente. Regra geral: se o valor grava uma janela de tempo que alguém pode tentar burlar, o "agora" vem do servidor.
- Depois de criar/alterar rota em `app/` (nome de arquivo, pasta, dinâmica), rode `npx expo start --web` uma vez (alguns segundos bastam) antes de confiar no `tsc`/editor — o Expo Router só regenera `.expo/types/router.d.ts` (rotas tipadas) durante o dev server, não com `expo export`. Sem isso, `router.push('/rota-nova')` falha o typecheck mesmo com o arquivo certo no lugar certo.
- `className` do NativeWind só funciona nos primitivos que ele mesmo intercepta (`View`, `Text`, `Pressable`... importados de `react-native`). Um componente do `react-native-reanimated` (`Animated.View`, ou algo novo criado com `Animated.createAnimatedComponent(...)`) é uma referência diferente — sem registrar (`cssInterop(Componente, { className: 'style' })`, ver `src/lib/nativewindAnimated.ts`), `className` nele é ignorado **silenciosamente** (nada quebra, o estilo simplesmente não aparece). Registre uma vez por componente animado, antes dele ser usado pela primeira vez.
- ESLint 10 (`eslint-config-expo`) trouxe a regra `react-hooks/immutability`, pensada pro React Compiler — ela não conhece o padrão do Reanimated (`useSharedValue(...).value = ...` é a API normal pra animar, não é estado do React) e marca falso positivo em toda atribuição a `.value`. É esperado precisar de `// eslint-disable-next-line react-hooks/immutability` nessas linhas (ver `src/components/ui/Button.tsx`) — não é sinal de bug.
